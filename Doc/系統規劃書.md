## 3. 共用元件：書架

總覽與圖書館共用同一套書架元件，規則如下。

- **書脊**：直立長條，顯示書名（直書）。厚度依 `word_count` 線性對應到最小 / 最大寬度；沒有字數的書用中間值（暫定）。
- **顏色**：後端在書封存檔時算出主色（Java 內建 `ImageIO` 縮到約 32×32，依色相分桶取最多的一桶，略過近白與近黑像素，再把飽和度與明度壓進和風範圍），存進 `spine_color`，匯入舊資料也走同一段。書名文字深淺依底色明度決定。沒有書封或無法解碼（如 WebP）時，退回書名雜湊和風色票。
- **已讀**：書脊套去飽和 + 降低亮度效果，實際灰色程度在 UI 階段調整。
- **借出中**：書脊上方掛小標籤「借出」（暫定紅褐色）。
- **互動**：hover 書脊往前抽出；點擊後書本攤開成雙頁：左頁書封，右頁基本資料（書名、作者、譯者、出版社、出版日期、分類、字數、已讀 / 完讀日期；購買連結所有人可見；書主額外看到金額、購買日期）。攤開頁下方放操作按鈕（見各頁說明）。
- **書架切換**：下拉或分段按鈕「我的書架 / 管理員書架」，預設我的；管理員登入時不顯示切換。
- 全部用 CSS transform / transition 實作，不加動畫套件。

## 4. 頁面規格

### 4.1 登入頁
- 只有「使用 Google 登入」按鈕。
- 第一次登入建立帳號，狀態待核准，顯示「已送出申請，等待管理員核准」，並寄信通知管理員。
- `ADMIN_EMAIL` 指定的帳號第一次登入自動成為管理員並直接可用，同時觸發舊資料歸屬（見第 9 節）。
- 通行證有效 30 天，過期或被停用回登入頁。

### 4.2 總覽
三個區塊，由上而下（手機）或左右分欄（桌機）：

1. **書架**：顯示所選書架近期購買的書（依 `buy_date` 新到舊，暫定 12 本，不足就有幾本放幾本）。點擊攤開書籍只有「詳情」內容，沒有維護。
2. **活動日曆**：撕頁日曆只顯示今天（月份、日期、星期幾），旁邊列出進行中的活動（依結束日期近到遠，顯示剩餘天數，馬拉松附細進度條）。點活動展開資訊：種類、日期區間、網址；馬拉松另顯示目前 / 目標分鐘數、階段進度條，並可直接登錄分鐘。整月月曆移到活動紀錄頁。日曆另檢查前 7 天（不含今天）有沒有填閱讀時數：只缺昨天時在日曆頁面上寫「尚未填入閱讀時數」；其他情況在日曆下方逐日列出「MM-dd 尚未填入閱讀時數」。點提示會到時數統計並選好那一天。
3. **租借中**：
   - 管理員看到：所有「申請中」與「借出中」的紀錄，每筆顯示借書人帳號（名稱 + Email）、書名、書封、狀態、日期，可直接核定借出 / 收回。
   - 一般使用者看到：自己申請中與借出中的書，可按歸還。
   - 沒有紀錄時顯示空狀態文字。

### 4.3 圖書館
- **上方工具列**：關鍵字搜尋（書名、ISBN、作者、譩者、出版社、分類名）、排序欄位 + 升降（書名、作者、出版社、出版日期、購買日期、完讀日期、金額、建立時間）、已讀 / 未讀 / 全部篩選、書架切換、新增按鈕、匯出按鈕。按下搜尋或變更條件後更新書架。
- **書架**：一頁上下兩座書架，每座桌機 10 本、寬度 1400px 以上 20 本、手機 5 本，長度跟著書走，兩側有木質擋板。左右箭頭切換上下一架，顯示「第 n / N 架」。
- **點擊書本**：直接攤開書籍（2026-11-06 改，原本先彈出「詳情 / 維護」選單）。攤開頁下方依身分顯示按鈕：書主有「維護」；看管理員書架時一般使用者有「借書」（書未借出且沒有進行中的申請時）。
- **新增 / 維護表單**（Modal）：書名（必填）、ISBN、作者（多個，逗號分隔）、譯者（多個）、出版社、出版日期、分類、字數、已讀 + 完讀日期、書封上傳（前端壓縮至 500KB 內轉 Base64，同 1.0）、購買金額、購買日期、購買連結。維護表單底部有刪除按鈕，需確認；書有進行中的借閱時不可刪除。
- **匯出**：前端取目前篩選條件下的全部書籍轉成 CSV（UTF-8 加 BOM，Excel 可直接開；暫定，若需要樣式再改 xlsx）。欄位同攤開頁可見欄位，看別人書架時不含金額與購買日期。

### 4.4 活動紀錄
- 活動列表（卡片或表格），可新增、編輯、刪除，依開始日期新到舊。
- **共用欄位**：種類（馬拉松 / 問答）、名稱、開始日期、結束日期、活動網址、顏色（日曆用）。
- **馬拉松額外欄位**：目標分鐘數、目前分鐘數（手動輸入）、階段分鐘數最多三個，由小到大，最後一個等於目標。表單輸入階段時自動把最後一階帶成目標值。
- 卡片顯示：進行中 / 未開始 / 已結束狀態、剩餘天數；馬拉松顯示進度條與已達到的階段。
- 可切換「列表 / 月曆」檢視（記在瀏覽器）。月曆為單月，可切上下月、回今天，每個活動以其顏色畫成橫跨日期的色條，點色條顯示活動資訊，進行中與未開始的馬拉松可登錄分鐘。種類篩選兩種檢視都適用。
- 活動屬於個人（暫定），管理員與其他人的活動互不可見。

### 4.5 閱讀統計
五個分頁，統計範圍只有自己的資料。

| 分頁 | 內容 |
|------|------|
| 閱讀紀錄 | KPI 卡：總書目數、已讀完、完讀比例、本年完讀、總閱讀時數、平均每日閱讀、閱讀天數 |
| 時數統計 | 上半：每日閱讀分鐘數的新增 / 修改 / 刪除（同一天只能一筆，選到已有紀錄的日期時改為更新；修改只改分鐘數；分鐘數 1～1440；每頁 10 筆）；下半：時數長條圖，「月」看所選年份的 12 個月、「年」看每一年 |
| 購買分析 | 同 1.0 六個子項：分類 / 出版社 / 作者 / 譯者的本數排行（分類用甜甜圈圖，其他長條圖只畫前 30 名，表格列全部）、購買力 KPI（總金額、平均書價、年均 / 月均 / 日均花費）、購買力分析（年 / 月花費長條圖含平均線與列表） |
| 完讀分析 | 只算已讀的書：分類 / 出版社 / 作者 / 譯者的本數排行（同購買分析）、月報 / 年報完讀長條圖 |
| 閱讀狀況 | 連續閱讀天數（從昨天往前算，每日 ≥ 20 分鐘）、里程碑等級與進度條：無 0、鐵 7、銅 30、銀 180、金 365、白金 750、鑽石 1500 天 |

圖表沿用 ECharts。KPI 與排行的計算公式照 1.0 搬，不重新定義。

## 5. 借書流程

```
借書人                         系統                          管理員
  │ 在管理員書架點「借書」        │                              │
  │ ───────────────────────────▶ │ 建立 loan: requested         │
  │                              │ 寄信給 ADMIN_EMAIL ─────────▶ │
  │                              │                              │ 總覽租借中 / 設定租借管理
  │                              │ ◀─────────────── 「核定借出」 │
  │                              │ loan: lent，書脊掛「借出」     │
  │ 總覽租借中按「歸還」           │                              │
  │ ───────────────────────────▶ │ loan: returned (ended_by=借書人) │
  │                              │ 寄信給 ADMIN_EMAIL ─────────▶ │
  │                              │                              │
  │                              │ ◀─────────────── 「收回」      │
  │                              │ loan: returned (ended_by=管理員) │
```

- 只能借管理員的書。一本書同時只能有一筆進行中（requested 或 lent）的紀錄。
- 不限借期，不做逾期。
- 申請中的紀錄管理員也可以直接「收回」當作拒絕（暫定，不另做拒絕狀態）。
- Email 兩封：申請時、借書人按歸還時。內容含借書人名稱與 Email、書名、時間、前往租借管理的連結。寄信失敗只記 log，不影響流程。
- 攤開書籍的操作按鈕依身分與狀態顯示：借書 / 歸還 / 核定借出 / 收回。
- 借書人對「申請中」可按「取消申請」（= 歸還，ended_by = borrower，不寄信）；管理員對申請中的按鈕叫「拒絕」（= 收回）。租借管理的結束欄會分別顯示「借書人歸還 / 借書人取消 / 管理員收回 / 管理員拒絕」。
- 攤開頁多一列「借閱」：申請中 / 借出中，借書人自己看到「你借的」，管理員看到借書人名稱。

## 7. 技術架構

### 7.1 Repo 結構（monorepo）
```
read-footprints/
├── Doc/                      # 本規劃書、資料結構、開發進度
├── frontend/                 # Vue 3 + Vite + Pinia + Bootstrap 5 + ECharts
│   └── src/
│       ├── api/              # axios instance 與各資源 service
│       ├── components/       # BookShelf, OpenBook, ActivityCalendar, ...
│       ├── views/            # OverviewPage, LibraryPage, ActivityPage, StatsPage, SettingsPage, LoginPage
│       ├── layouts/MainLayout.vue
│       ├── stores/           # auth, books, categories, activities, readingLogs, loans
│       ├── utils/            # 統計計算、日期、書脊厚度等純函式（附 node --test）
│       ├── router/index.js   # hash 模式，避免 Pages 子路徑 404
│       └── css/theme.css     # 日式書房配色與字體變數
├── backend/                  # Java 21 + Spring Boot 4，Maven Wrapper

│       ├── config/           # AppProperties, AuthFilter, WebConfig(CORS), MongoConfig
│       ├── controller/

│       ├── model/
│       └── migration/        # LegacyImporter（一次性匯入 1.0）

```
前端沿用 alex-code-style 的分層命名；因 Railway 需要 Root Directory，後端放 `backend/` 而非 `server/`（暫定）。

### 7.2 後端
- 直接複製 to-do-schedule 的 `AuthFilter`、`GoogleVerifier`、`TokenService`、`UserService`、`AppProperties`、`WebConfig`、`EmailService`，改 package 名與文案。
- 錯誤回應採 Spring Problem Details，中文訊息放 `detail`；前端攔截器統一顯示。
- JSON 與 Mongo 欄位皆 snake_case。
- 列表 API 分頁參數 `page`、`size`，回 `{ items, total, page, size }`。
- 書籍列表預設不回 `cover` 欄位，書架只有攤開時才另外取（同 1.0 的 includeImage 作法，避免每架 20 本 Base64 一起下載）。

- 不用 vue-good-table、vue-select、vuedraggable、xlsx-js-style（1.0 相依全部拿掉）。

`_id`, `user_id`, `name`, `legacy_id`。索引 `{user_id, name}` unique。

### reading_logs（1.0 time_data）
`_id`, `user_id`, `date`, `minutes`。索引 `{user_id, date}` unique。

### activities

1.0 的活動遷入時 type = marathon、url 空、stage_minutes = [goalTime]。

### loans

索引：`{book_id, status}`、`{borrower_id, status}`、`active_book_id`（unique, sparse）。

## 10. API 清單

| Method | Path | 說明 |
|--------|------|------|
| POST | /api/auth/google | Google 登入，回 token + user |
| GET | /api/auth/me | 目前使用者 |
| GET | /api/books | 每本書帶 `loan`（進行中的借閱：id、status、mine、管理員才有的 borrower_name），沒有則 null。query：shelf(mine/admin), keyword, read(all/read/unread), sort, order, page（從 1 起）, size（上限 5000）；回 `{ items, total, read_count, page, size }`。看別人書架時 price / buy_date 為 null，不可依金額排序 |
| GET | /api/books/{id} | 單本含 cover；非書主且非管理員的書回 404 |
| POST / PUT / DELETE | /api/books, /api/books/{id} | 書主限定。cover：不傳 = 不變、空字串 = 移除 |
| GET / POST / PUT / DELETE | /api/categories… | 自己的分類 |
| GET / POST / PUT / DELETE | /api/reading-logs… | GET query：from, to（可省略，含頭尾，新到舊）；POST { date, minutes }，同日重複回 409；PUT 只改 minutes |
| GET / POST / PUT / DELETE | /api/activities… | 自己的全部活動，新到舊；日曆由前端篩選 |
| GET | /api/stats/summary | 回 total_books、read_books、read_this_year、total_minutes、reading_days、streak_days；比例、平均、里程碑由前端算。「今天」以台北時間為準 |
| POST | /api/loans | 申請借書 { book_id } |
| GET | /api/loans | 自己的借閱；管理員帶 `?all=true` 看全部；`?status=` 篩選 requested / lent / returned / active（進行中，會附書封給總覽用）。回傳帶書名、書脊色、借書人名稱 / Email / 大頭貼 |
| POST | /api/loans/{id}/lend | 管理員核定借出 |
| POST | /api/loans/{id}/return | 借書人歸還 |
| POST | /api/loans/{id}/reclaim | 管理員收回 |
| GET | /api/admin/users | 使用者列表 |
| PUT | /api/admin/users/{id}/status | 核准 / 停用 |
| GET | /api/ping | 健康檢查，不需登入 |

購買分析與完讀分析的排行、分布由前端用 `/api/books?size=全部` 的結果計算（同 1.0 作法，書量在千本以下沒問題；暫定）。
