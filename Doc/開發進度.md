## 階段 0：骨架與登入（程式完成，2026-11-05，待上線）

完成：
- monorepo：`frontend/`、`backend/`、`Doc/`、GitHub Pages workflow。
- 後端 Spring Boot 4.1.1 / Java 21：Google 登入（`POST /api/auth/google`）、通行證 30 天、`AuthFilter` 擋所有 `/api/**`、使用者核准 API（`/api/admin/users`）、新申請寄信給管理員、`/api/ping`、actuator health。登入骨架自 to-do-schedule 複製改名。
- 前端 Vue 3 + Bootstrap 5：日式書房主題變數 `src/css/theme.css`、登入頁（GSI 按鈕）、側邊欄五頁籤、設定頁「使用者核准」與「個人資料」分頁、待核准徽章、Toast。其餘頁面為佔位。
- 本機驗證：`mvnw package` 含 TokenServiceTest 通過；`npm run build` 通過；jar 啟動後 ping / 401 / 登入錯誤 / health 回應正確。

上線前需要使用者做的事（規劃書第 14 節）：
1. GitHub：Settings → Pages → Source 選 GitHub Actions；Secrets 填 `VITE_API_BASE_URL`、`VITE_GOOGLE_CLIENT_ID`。
2. Railway：新專案連 repo，Root Directory `backend`，填 README 表格的環境變數。
3. Atlas：資料庫名 `read_footprints`（同 cluster 即可）。
4. Google OAuth 用戶端 ID：可直接用 to-do-schedule 的（來源 `https://alexsuze.github.io` 與 `http://localhost:5173` 相同）。

驗證項目：
- [ ] 以 ADMIN_EMAIL 的 Google 帳號登入，進到總覽。
- [ ] 以第二個 Google 帳號登入，看到「等待核准」，管理員收到通知信。
- [ ] 管理員在設定 → 使用者核准看到該帳號並核准；第二帳號可登入。
